# User Stories for StudExplore

This document outlines the user stories for the StudExplore platform, categorized by user type and feature area.

## 1. Student User

### 1.1. Account Management & Profile
*   **US-S001:** As a student, I want to register for a new account using my email and a password, so that I can access the platform's features.
*   **US-S002:** As a student, I want to log in to my existing account securely, so that my personal information and application history are protected.
*   **US-S003:** As a student, I want to view and edit my profile information (including name, email, major, graduation year, skills, and a short bio), so that I can present an accurate and compelling profile to opportunity providers.
*   **US-S004:** As a student, I want to be able to reset my password if I forget it, so that I can regain access to my account.
*   **US-S005:** As a student, I want to be able to delete my account and personal data, so that I have control over my information.

### 1.2. Opportunity Discovery & Browsing
*   **US-S006:** As a student, I want to browse a list of all available opportunities, so that I can get an overview of what's available.
*   **US-S007:** As a student, I want to search for opportunities using keywords (e.g., "software intern", "marketing", "biology research"), so that I can find relevant listings quickly.
*   **US-S008:** As a student, I want to filter opportunities by type (e.g., Internship, Job, Scholarship, Volunteer), location, industry, and required skills, so that I can narrow down my search to the most suitable options.
*   **US-S009:** As a student, I want to view detailed information for each opportunity, including title, description, company/organization, location, type, requirements, deadline, stipend (if any), and duration, so that I can make an informed decision about applying.
*   **US-S010:** As a student, I want to see when an opportunity was posted, so I know how recent it is.
*   **US-S011:** As a student, I want to be able to save or bookmark opportunities I am interested in, so that I can easily find and review them later.

### 1.3. Application Process
*   **US-S012:** As a student, I want to apply for an opportunity directly through the platform (if supported by the provider) or be directed to an external application link, so that the application process is clear and accessible.
*   **US-S013:** As a student, I want to view a list of all opportunities I have applied for, so that I can keep track of my applications.
*   **US-S014:** As a student, I want to see the status of my submitted applications (e.g., Submitted, Reviewed, Interviewing, Offered, Rejected, Withdrawn), so that I am aware of my progress.
*   **US-S015:** As a student, I want to be able to withdraw an application if I am no longer interested or available.

### 1.4. Notifications
*   **US-S016:** As a student, I want to receive notifications when the status of my application changes, so that I am promptly informed.
*   **US-S017:** As a student, I want to receive notifications for new opportunities that match my saved preferences or profile, so that I don't miss relevant listings.
*   **US-S018:** As a student, I want to manage my notification preferences, so that I only receive alerts I find useful.

## 2. Company Representative / Opportunity Provider User

### 2.1. Account Management & Profile
*   **US-C001:** As a company representative, I want to register an account for my organization, so that we can post and manage opportunities.
*   **US-C002:** As a company representative, I want to log in to my organization's account securely.
*   **US-C003:** As a company representative, I want to view and edit my organization's profile (including name, industry, location, description), so that students can learn about our company/organization.

### 2.2. Opportunity Management
*   **US-C004:** As a company representative, I want to create and post new opportunity listings, providing all relevant details (title, description, type, location, requirements, deadline, etc.), so that I can attract qualified student applicants.
*   **US-C005:** As a company representative, I want to view a dashboard of all opportunities posted by my organization, so that I can manage them efficiently.
*   **US-C006:** As a company representative, I want to edit the details of an existing opportunity, so that I can correct information or update requirements.
*   **US-C007:** As a company representative, I want to close or archive an opportunity listing when it is filled or no longer available.

### 2.3. Application Management
*   **US-C008:** As a company representative, I want to view a list of students who have applied for each of our opportunities, so that I can begin the review process.
*   **US-C009:** As a company representative, I want to view the profile and application details of each applicant, so that I can assess their suitability for the opportunity.
*   **US-C010:** As a company representative, I want to update the status of applications (e.g., Reviewed, Interviewing, Offered, Rejected), so that both our team and the students are informed of the progress.

### 2.4. Notifications
*   **US-C011:** As a company representative, I want to receive notifications when a new application is submitted for one of our opportunities, so that I can review it in a timely manner.

## 3. General / System (Implied)
*   **US-G001:** As a user, I want the website to be responsive and accessible on various devices (desktop, tablet, mobile), so that I can use it conveniently.
*   **US-G002:** As a user, I want the platform to have clear navigation and an intuitive user interface, so that I can easily find what I'm looking for.
*   **US-G003:** As a user, I want my personal data to be handled securely and in accordance with privacy regulations.
