# Resources

This document lists the key resources for the Student Opportunities Hub project.

## Core Resources

-   **User:** Represents students, school staff, and company representatives who interact with the platform.
-   **Application:** Represents a student's application for an opportunity.
-   **Opportunity:** Represents internships, jobs, scholarships, volunteer positions, or other programs available to students.
-   **Notification:** Represents alerts and messages sent to users (e.g., application status updates, new opportunity alerts).

## Authentication

-   **Login:** Handles user authentication and session management.
